01 / Masalah

Kelemahan Agen Coding Berbasis Runtime Tradisional

Kakas seperti Claude Code dan Codex membuktikan nilai tinggi AI di CLI, namun mayoritas dibangun dengan Node.js atau Python:

  • RAM Boros: Menyerap 150–300 MB RAM hanya untuk status siaga (idle).
  • Waktu Startup Lambat: Jeda 300–600 milidetik saat inisialisasi modul runtime V8/Python.
  • Distribusi Rapuh: Ketergantungan pada npm, pip, atau bundel raksasa (> 80 MB).
  • Terkunci Satu Model: Sebagian besar agen mengunci pengguna ke satu penyedia API tertentu.

05 / Keamanan & Perkakas

Developer Tool Suite & Human-in-the-Loop Safety

Agen hanya mengusulkan tindakan, manusia memegang kendali eksekusi:

  • read_file: Membaca berkas dengan nomor baris & batasan rentang baris.
  • write_file: Membuat berkas baru atau menimpa secara aman (destruktif).
  • edit_file: Penggantian teks bedah secara presisi (destruktif).
  • run_command: Eksekusi terminal lokal dengan timeout protektif (destruktif).
  • list_dir: Penelusuran struktur hierarki direktori proyek.

Dialog Interaktif HITL

07 / Distribusi & Ekosistem

Distribusi Biner Multi-OS & Landing Page CrootJS

Otomatisasi pengiriman perangkat lunak modern tanpa intervensi manual:

  • GitHub Actions Matrix: Mengompilasi 4 target biner: Linux x86_64, macOS Apple Silicon (arm64), macOS Intel, dan Windows x86_64.
  • Auto-Tagging & Releases: Membuat rilis otomatis dan menyertakan checksum SHA256.
  • Landing Page CrootJS: Mengakses API GitHub Releases secara dinamis untuk mendeteksi OS pengunjung dan menyajikan tombol unduh 1-klik.
  • Instalasi 1-Baris: Skrip install.sh dan install.ps1 siap pakai.
