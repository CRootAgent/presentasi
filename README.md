## 🎮 Kontrol Navigasi

- **Panah Kanan ($\rightarrow$) / Spasi:** Terbang ke slide / node berikutnya di ruang 3D.
- **Panah Kiri ($\leftarrow$):** Kembali ke slide / node sebelumnya.
- **Esc:** Kembali ke *Big Picture Overview* (Peta Konsep).
- **Klik pada Kartu Peta:** Kamera 3D langsung terbang memperbesar ke bagian yang diklik.
- **HUD Kontrol:** Tersedia tombol visual di pojok kanan bawah layar.
